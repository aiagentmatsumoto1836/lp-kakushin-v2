# LPレビューSkill

静的LP（HTML/CSS/JS）の品質を多角的にレビューし、改善点を提示・修正する。

## ワークフロー

TodoWriteツールでタスクリストを作成し、順番に進める。

### 1. lp-context.md の読み込み

まず `lp-context.md` を読み込み、プロジェクト情報を把握する：

```bash
cat lp-context.md 2>/dev/null || echo "lp-context.md が見つかりません"
```

読み込んだ内容を以下のレビューで活用する：
- **SEOチェック**: `lp-context.md` のキーワードがHTMLに含まれているか確認
- **メッセージ確認**: キャッチコピー・CTA文言がlp-context.mdと一致しているか確認
- **デザイン確認**: カラーコードがlp-context.mdのメインカラー・アクセントカラーと一致しているか確認

### 2. ファイル構造の確認

```bash
# プロジェクトルートのファイルを確認
ls -la
ls css/ js/ images/ 2>/dev/null
```

### 2. HTMLレビュー

**index.html を読み込み、以下を確認：**

#### 必須メタタグ
- [ ] `<meta charset="UTF-8">`
- [ ] `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- [ ] `<meta name="description" content="...">` (120〜160文字)
- [ ] `<title>` タグ (30〜60文字)
- [ ] OGP タグ (`og:title`, `og:description`, `og:image`, `og:url`)

#### HTML構造
- [ ] セマンティックHTML（`header`, `main`, `footer`, `section`, `article`など）
- [ ] 見出し階層が正しい（h1 → h2 → h3 の順）
- [ ] h1 はページに1つだけ
- [ ] 画像に `alt` 属性がある
- [ ] CTAボタンに明確なテキストがある
- [ ] フォームがある場合、`label` と `input` が紐づいている

#### アクセシビリティ
- [ ] `lang="ja"` が設定されている
- [ ] フォーカス可能な要素がキーボード操作できる
- [ ] リンクテキストが「こちら」「クリック」などの曖昧な表現でない

### 3. CSSレビュー

**css/style.css を読み込み、以下を確認：**

#### レスポンシブ対応
- [ ] `@media (max-width: 768px)` などのブレークポイントがある
- [ ] `width: 100%` や `max-width` で横スクロールが発生しない
- [ ] フォントサイズがモバイルで読みやすい（最低14px）
- [ ] タップターゲットが十分な大きさ（最低44×44px）

#### パフォーマンス
- [ ] 不要なCSSが少ない
- [ ] アニメーションに `transform` や `opacity` を使っている（`left/top` より効率的）

#### デザイン一貫性
- [ ] カラーがCSS変数（カスタムプロパティ）で管理されている
- [ ] フォントファミリーが統一されている

### 4. JSレビュー

**js/main.js を読み込み、以下を確認：**

- [ ] `'use strict'` が使われている
- [ ] `DOMContentLoaded` か `defer` でスクリプトが実行される
- [ ] コンソールエラーが発生しないコードになっている
- [ ] セキュリティ上問題のある `innerHTML` への未サニタイズ代入がない
- [ ] 外部APIを呼ぶ場合、エラーハンドリングがある

### 5. SEOチェック

- [ ] ページタイトルにキーワードが含まれている
- [ ] meta descriptionにキーワードと行動喚起が含まれている
- [ ] h1にメインキーワードが含まれている
- [ ] 画像ファイル名が意味のある名前になっている
- [ ] 内部リンクに適切なアンカーテキストが使われている

### 6. パフォーマンスチェック

- [ ] 画像に `loading="lazy"` が設定されている（ファーストビュー以外）
- [ ] CSSが `<head>` 内に、JSが `<body>` 末尾か `defer` で読み込まれている
- [ ] Webフォントは非同期で読み込まれている（`font-display: swap`）
- [ ] 画像が適切なサイズ（幅2000px超の画像がない）

### 7. レビュー結果の報告

以下の形式で報告する：

```
## LPレビュー結果

### ✅ 問題なし
- （問題のない項目）

### ⚠️ 改善推奨
- （優先度低〜中の改善点）

### ❌ 要修正
- （公開前に必ず修正すべき問題）

### 修正提案
（具体的な修正コードを提示）
```

### 8. 自動修正の実行

ユーザーが同意した場合、または明らかなバグ・問題は即座に修正する：
- 欠けているメタタグの追加
- alt属性の追加
- 画像への `loading="lazy"` の追加
- 明らかなHTMLバリデーションエラーの修正

修正後は「修正完了」と変更内容をサマリーで報告する。
